# Bianca Vance - Fashion Designer Portfolio

A modern, high-fashion portfolio website built with React, TypeScript, Vite, and Tailwind CSS. This project serves as a sleek and performant showcase for haute couture, bridal wear, and ready-to-wear collections.

## Features

- **Responsive Design**: Flawless aesthetic across desktop, tablet, and mobile devices.
- **Dynamic Portfolio**: Filterable gallery for different fashion collections.
- **Modern Tech Stack**:
  - React 18
  - TypeScript
  - Vite for lightning-fast HMR and building
  - Tailwind CSS for utility-first styling
  - Lucide React & React Icons for scalable iconography

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```

2. Navigate into the project directory:
   ```bash
   cd Fashion-Designer
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### Build

To create a production-ready build:

```bash
npm run build
```

This will generate a `dist` folder containing the optimized static assets.

## Project Structure

- `src/App.tsx`: Main application component containing the portfolio sections.
- `src/index.css`: Global styles and Tailwind configuration.
- `src/assets`: Images and icons used in the project.
